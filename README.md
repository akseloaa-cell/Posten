# Posten — Postal Empire

Et nettleserbasert manager- og strategispill der du bygger opp et postsystem. Målet er å kombinere logistikk og ruteplanlegging med langsiktig utvikling inspirert av strategispill.

## Spill nå

Åpne `index.html` i en nettleser, eller publiser repoet med GitHub Pages.

Ingen byggesteg eller eksterne JavaScript-biblioteker er nødvendig. Google Fonts brukes for typografi; systemfonter fungerer også uten nett.

## Første prototype

- Seks norske byer med ulik befolkning og postetterspørsel
- Postkontorer og sorteringssentre
- Ruter mellom byer
- Månedlige inntekter, utgifter og leveranser
- Omdømme og fremgang over tid
- Automatisk lagring i nettleserens localStorage

## Mappestruktur

- `index.html` — spillgrensesnitt
- `css/style.css` — visuell utforming og responsiv layout
- `js/data.js` — startverdier, byer og balanse
- `js/state.js` — spilltilstand og lagring
- `js/economy.js` — månedlig økonomi
- `js/logistics.js` — bygg og ruter
- `js/game.js` — spillrunder
- `js/main.js` — kobler spillogikken til grensesnittet

## Plan videre

1. Teste og balansere økonomi og postflyt
2. Gjøre kartet mer geografisk og interaktivt
3. Legge til teknologitre og historiske epoker
4. Utvide transporttyper og sorteringskapasitet
5. Legge til hendelser, mål og flere lagringsvalg

Dette er en tidlig prototype. Økonomi og logistikk er foreløpig forenklet.
